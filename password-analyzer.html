    How it works

    Each check earns one point: eight or more characters, an uppercase letter, a lowercase letter, a digit, and one of !@#$%^&*. Matching personal information triggers a warning without changing the score.

    The analyzer hashes the password locally with SHA-1, requests matching hash suffixes from Pwned Passwords using only the first five hash characters, and compares the suffix locally. A match deducts two points; more than 100,000 reported occurrences resets the score to zero, matching the Python implementation.

    The score is a rule-based demonstration, not a prediction of the likelihood of being hacked. Breach counts describe reported password occurrences, not a count of distinct breach events. Blank optional personal fields are ignored.
